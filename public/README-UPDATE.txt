SECTOR-9: ЭХО — обновление

Файлы:
- server.js — сервер + закрытый admin API
- public/index.html — интерфейс
- public/app.js — игра, журнал действий, выбор глав, админ-панель
- public/sector9-audio.js — бесшовная фоновая музыка и раздельная громкость
- public/style.css — стили
- public/krik-v-pustote-2-b72ee5.mp3 — музыкальный файл

Переменные Render:
ADMIN_TELEGRAM_ID = ваш числовой Telegram ID (секретно)
Остальные переменные BOT_TOKEN, APP_URL, DATABASE_URL остаются как были.

Важно: админ-панель открывается только после проверки Telegram initData на сервере и совпадения ID с ADMIN_TELEGRAM_ID. Не публикуйте этот ID в коде.

Музыка начинает играть после первого нажатия в Mini App (ограничение браузеров на autoplay), затем продолжает играть при смене экранов и сцен. При скрытии приложения ставится на паузу и продолжается при возвращении.
